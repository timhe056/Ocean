## M1 详情（当前版本）

**目标**：验证"驾驶船只航行于起伏海面"的核心手感。

**已实现**：

- Gerstner 波海面（4 个波分量，60m~9m 波长），GPU 顶点位移 + 逐像素解析法线
- 海面着色：菲涅尔天空反射、波峰透光（SSS 近似）、浪峰白沫（whitecaps：坡度破碎判据 + 无缝噪声纹理 + 距离淡出，覆盖率随海况自动分级）
- `WaveProvider` 模块：波形参数唯一数据源，CPU 物理与 GPU 渲染共享，保证视觉浪 = 物理浪（后于 M2 升级为蒲福连续插值）
- 船只：4 点浮力采样（自然纵摇/横摇）、推进、舵效随航速变化、龙骨侧向水阻、风压差漂移
- 跟随相机：平滑跟随 + 鼠标环顾 + 缓慢回正
- 场景：自定义天空 + ACES 色调映射 + 距离雾、HUD（速度/油门/浪高/风力/事件/能见度）

**验证数据**（自动化运行实测）：

| 项目 | 结果 |
|------|------|
| 浮力平衡 | 船体原点稳定在浪面 ±0.05m 内，随浪起伏 ✓ |
| 推进 | 全速约 11 节，收敛干净无振荡 ✓ |
| 舵效 | 转弯速率约 20°/s，松舵有余势 ✓ |
| 稳定性 | 窗口/无头模式运行均无脚本与 shader 错误 ✓ |
| 海况切换 | 中等→风暴浪高 4s 平滑收敛 ±2.2m→±3.4m，无跳变 ✓ |

**操作**：W/S 油门（可倒车）、A/D 舵、1/2/3 手动设风（轻风/和风/大风）、4雨/5雷/6雾/7涌 手动触发天气事件、0 恢复晴好、T 时间加速 ×30、[/] 时刻 ±0.5h、C 潜水、鼠标环顾、Esc 释放鼠标。

## 海面网格图案问题（2026-10-07 修复，四层根因）

用户报告海面偶现排列的方形图案，经截图对照逐层定位为四个独立成因，全部修复：

1. **9m 波顶点混叠**：波长 < 网格奈奎斯特下限（5.9m/格 × 2）→ 仅前 3 个大波做顶点位移（`displace_count`），9m 波只进逐像素法线
2. **掠射角几何摩尔纹**：远处位移三角形被压成亚像素 → 顶点位移随相机距离 150~700m 淡出，细节由平滑的逐像素法线接管
3. **逐像素小信号远距混叠**：9m/17m 波法线、浪高、噪声在远处缩到像素尺度混叠成规则点阵（浅色区域最显眼）→ fragment 细节随距离 150~500m 统一淡出（`detail_fade`）
4. **白沫格点晶格**：value noise → Perlin → fbm → 域扭曲均无法消除"阈值切格点场导致泡沫覆盖率按格相关"的格子感 → 最终换为无缝噪声纹理（NoiseTexture2D，Simplex fbm 4 八度，双尺度反向漂移采样），硬件双线性过滤 + mipmap 一次性根除晶格接缝、瓦片边缘与远距混叠

另：白沫/透光改用逐像素解析浪高 `wave_height_at()`（原为顶点 varying 插值，三角形边界梯度突变会被阈值切割成网格纹）。

**白沫判据演进**（2026-10-07）：原为绝对浪高阈值，风暴档浪高上限 4.3m 导致整个浪峰饱和糊白 → 改为坡度主导判据（`1 - n.y`，物理上白沫产生在波面过陡即将破碎处），浪高仅作小修正。三档覆盖率自动分级：平静几乎无白沫、中等偶现、风暴呈条状碎浪带。

**回归工具**：`godot --path . --script res://prototype/_shot_test.gd`（多机位截图）、`_sea_state_test.gd`（海况切换数值校验）；shader 的 `debug_view=1` 可输出白沫 mask 灰度图。用户反馈样本存于 `docs/debug/`。

## M2 详情（天气系统 v2）

- **蒲福连续化**：`wave_provider.gd` 的 `WIND_TABLE` 关键帧（2/4/6/8/10/11.5 级六档）连续插值，`set_wind(级)` 按 0.5 级/秒渐变；实测 11 级浪高 ±7.9m
- **三轴模型**（`weather.gd`）：wind（蒲福级连续）/ precip（降水）/ fog（海雾）+ gust 阵风尖峰；事件编舞：锋面降雨、雷暴飑线（阵风锋 +3 级急升衰减）、海雾（仅小风触发）；事件间马尔可夫链，雷暴冷却 20 分钟（罕见惊喜）
- **天气影响航行**：5 级以上风压差推船漂移，能见度由雾+降水合成显示在 HUD
- **手动**：1/2/3 = 轻风/和风/大风，锁定 120s
- **W2 降水**（`rain.gd`）：雨幕粒子（4000 细长条、随风倾斜、跟随相机、入水隐藏）+ 海面涟漪（法线高频扰动 + 粗糙度微增）+ 能见度接入
- **W3 海雾**：fog 轴驱动距离雾（能见度 3km→120m），截图验证
- **W4 雷电**（`lightning.gd`）：雷暴事件窗口内随机闪电——天空方位性闪光 + 锯齿状闪电光柱（sky shader 按 `flash_seed` 每次生成不同形状，云底劈到地平线）+ 平行光脉冲 + 程序合成雷声（布朗噪声爆发，延迟=距离/340m/s，远闷近炸）；天空阴霾度取 风/降水 最大值驱动（雷暴未到风峰也已乌云密布），风暴时雾色同步压暗
- **W5 涌浪预警**：`WaveProvider` 新增涌浪通道 `set_swell()`——改写最大波分量（波长→200m/周期~11.3s、波幅抬至 ≥1.6m、坡度放缓），浪变高变长但风不变；`weather.gd` 新增"涌浪预警"事件（1~3min），结束后 30~90s 内强制跟随锋面降雨/雷暴（` _pending_storm`），实测浪高 0.91m→1.95m 风力不变
- **W5 音效**（`ambience.gd`）：程序合成环境音，无音频资源——布朗噪声风声（音量/亮度随蒲福级，双正弦阵风起伏）+ 白噪声雨声（随 precip），入水低通闷化+音量 1/4；AudioStreamGenerator 22.05kHz 每帧填缓冲
- **W6 昼夜循环**（`day_night.gd`）：唯一时间数据源，一昼夜=10min（可调），6 点日出 18 点日落；昼夜调制太阳高度角/光照，天气轴调制云/雨/雾（天空控制权分工）；夜晚月亮接管平行光（冷色微光 0.16），sky shader 新增星空（哈希格点+闪烁）、月亮盘、晨昏地平线暖调；能见度夜晚打 55 折；[/] 键 ±0.5h
- 验证：2000s 模拟事件循环/雷暴冷却/手动锁定/涌浪→风暴跟随均通过；雨峰/雨衰/海雾/闪电/涌浪/昼夜四时刻截图（`_w56_shot_test.gd`）

## M3 详情（天空与大气）

- `sky.gdshader`：自定义天空（晴空渐变 + 太阳 + 云），替换 PhysicalSky
- 天气强度（`provider.current_intensity()`，按实际混合浪高归一化）每帧驱动：天色晴蓝↔铅灰、云量、太阳强度衰减、平行光、雾密度、海面反射天色；阴霾度取 风/降水 最大值（雷暴未到风峰已乌云密布）
- **云 v2**（2026-10-08）：Simplex 无缝噪声纹理 + 三尺度云形（云堤/积云/碎边）+ 超大尺度密度场（有云区与留白区，分布不均匀）+ 沿风向压缩成云街；`cloud_character`/`sky_cover_bias` 两个慢速随机游走让天空隔几分钟换性格（碧空散云↔大片云层），风暴自动锁回满天低云
- 云随风漂移，风速随强度增大；强度取波浪混合值 → 海况过渡时天空与海浪天然同步

## M7 详情（水下世界 v1）

- **潜水相机**（`dive_camera.gd`）：C 键切换船上/潜水，0.8s 平滑过渡，出生点在船侧水面下；WASD + Space/Ctrl 升降 + Shift 加速；潜水时船油门归零、保留浮力
- **水下渲染**：相机低于波面自动过渡（0.3s）——雾变浓变青、环境光压暗、背景由 sky shader 的 `underwater` uniform 切换为上明下暗的水色；海面双面渲染，水下抬头见透光"天花板"（自发光建模，浪峰透光 + 太阳透光亮斑）
- **程序海床**（`terrain.gd` + `seabed.gdshader`）：固定 seed 噪声高度场（确定性，`get_height`/`get_biome` 是唯一数据源），四生态区（浅滩沙地/藻场/岩礁/深海平原）；3×3 区块跟随相机，每帧限生成 1 块；着色按生态区顶点色混色 + 坡度岩石化 + 深度压暗 + 焦散（噪声零交叉网纹，浅水强、风暴弱）；海面网格已关闭投影（否则海床全在阴影里）
- **水上透视海底**（2026-10-08，`ocean.gdshader`）：屏幕空间折射（`DEPTH_TEXTURE`/`SCREEN_TEXTURE`）——按水深衰减透出海底（浅滩沙地可见焦散网纹，深海不可见），水体吸收红光偏青、波面法线扭曲折射（浪动海底晃）、菲涅尔掠射角自动遮挡；浑浊度随风浪/降水升高（风暴后海水变浑）；海面因此改走透明通道渲染（`blend_mix` + ALPHA=1 + render_priority=-1 画在雨幕前）——这是深度纹理不含水面自身的前提
- **观赏鱼群**（`fish_school.gd` + `fish_manager.gd`）：MultiMesh 程序化三角片小鱼，锚点伪群游（O(n)，无近邻搜索），相机 8m 内四散；按生态区配置生成（浅滩银鱼大群/藻场绿鱼/岩礁彩色中鱼/深海稀少大鱼），150m 回收；10-08：顶点着色器摆尾动画（INSTANCE_CUSTOM 相位/频率，受惊加快）+ 生态区过渡带混游（30% 次生态区颜色/体型）
- **水下氛围**（10-08）：`god_rays.gd` 体积光柱（MultiMesh 圆柱广告牌 + 噪声条纹加性混合，沿太阳轴倾斜，强度=水下×日照×清澈度）；`ambience.gd` 水下通道（低频涌动 + 随机气泡 chirp）
- **修复**：`fragment()` 不能用 `return`（Godot shader 限制）改为 if/else；海床 ArrayMesh 三角形绕序与法线（差分法线）

**验证**：地形确定性/高度范围/生态区分布（`_terrain_test.gd`）✓；潜水五连拍（`_dive_test.gd`：仰视海面/平视/海床焦散/鱼群/水面回归）✓；无头 600 帧零报错 ✓

## M4 详情（FFT 海面）

- **F1 核心**（`prototype/fft/FftOcean.cs`，C#）：Phillips+JONSWAP 谱 → h̃(k,t) 演化 → 128×128 IFFT（1.36ms）；谱幅按 Gerstner σ 校准（手感一致）；固定 seed 确定性；验证 `_fft_test.gd`
- **F2 渲染接入**：`WaveProvider` 新增后端切换（B 键，HUD 显示）——FFT 高度场每 2 帧上传为纹理（FORMAT_RF+mipmap），顶点位移/物理用 5×5 平滑场（防 5.9m 网格混叠，与 Gerstner 的 displace_count 同思想），fragment 法线用全分辨率场差分；白沫/SSS 用 lod1 平滑场（否则短波能量把坡度/浪高打满）；浮力物理改走 `SampleBilinear`（CPU/GPU 同一份数据）
- **排掉的坑**：SampleBilinear 坐标换算错误（物理采样错位，船悬空）；盒式模糊回写覆盖全分辨率场（中间缓冲必须独立）；风浪渐变时谱重建阈值 0.25 级
- **已知**：FFT 场远处法线被 mipmap 平均 → 远景比 Gerstner 更"镜面"（物理上合理，美感待试玩）；FFT 后端暂不支持涌浪通道（F4）；8 级浪谷会把浅水鱼群露出水面（depth_max 应随浪高调整）
