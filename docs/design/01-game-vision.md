# 01 · 游戏愿景与核心体验

## 一句话概念

玩家驾驶船只在**尽可能真实的大海**上冒险——天气与海况按照真实世界的规律变化，大海既是舞台，也是对手。

## 核心体验支柱

1. **真实的海**
   - 海面视觉与物理一致：看到的浪就是托住船的浪。
   - 多种天气下的海况差异显著且符合直觉（对应蒲福风级）：平静时如镜，风暴时如山。
   - 目标是"相信这是真的海"，而不是"好看的水"。

2. **真实的天气**
   - 天气是一个系统而非贴图：风、云、雨、雾、雷电、光照、海况全部联动，由统一的天气状态驱动。
   - 可选的"拟真模式"：接入真实气象数据（Open-Meteo），让玩家在现实世界的某片海域航行。

3. **有分量的船**
   - 船有惯性、会纵摇横摇、转向有余势；风暴中船难以操控。
   - 手感优先级高于拟真度：允许为手感妥协物理精度，但不允许"船像开车"。

4. **可探索的水下**
   - 自由潜水相机随时下水：程序生成的海床生态区（浅滩沙地/藻场/岩礁/深海平原）+ 按生态区分布的观赏鱼群。
   - 水下氛围与水上天气联动：风暴时水下变暗、焦散减弱。

## 目标平台与受众

- **平台**：PC（Windows，D3D12 / Forward+）。FFT compute shader + 体积云的方案排除了移动端和 Web。
- **受众**：喜欢《Sea of Thieves》的海、但想要更写实体验的玩家；航海模拟爱好者。

## 美术方向

- 写实风格，ACES 色调映射，自然光照（物理天空 + 太阳）。
- 海面带写 50% 靠天空：天空质量（物理大气散射 + 体积云）与海面带写同等重要。
- 标志性画面目标：逆光时浪峰透光（SSS）、风暴前乌云压顶、暴雨中能见度骤降。

## 暂不追求（明确排除，防止 scope 蔓延）

- 多人联机
- 移动端 / Web 平台
- 真实的全球地图与航线模拟（先做"一片海"，不做"整个地球"）
- 角色级潜水玩法（体力/氧气/装备）；水下目前是自由相机观光，不是生存玩法
