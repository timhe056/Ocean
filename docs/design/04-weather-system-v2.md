# 04 · 天气系统 v2 设计：从"只有风"到完整海上天气

> 状态：设计方案，待评审
> 关联：M2（天气状态机 v1，已完成）、M5（氛围）、愿景文档第二支柱"真实的天气"

## 现状与问题

当前天气系统（`weather.gd`）只有**一个轴：风**。三档海况（蒲福 2-3 / 4-5 / 7-8 级）+ 相邻转移 + 手动覆盖。天空、光照、雾、海况全部从风力插值。

但真实海上的天气体验是**多维度、且各维度并不总同步**的：

- 倾盆大雨可以发生在风平浪静时（热带阵雨）
- 海雾往往出现在**风很小**的时候（平流雾），大风反而吹散
- 雷暴飑线过境时风速会**突然**飙升再回落（阵风锋），与慢慢演变的背景风不同
- 风暴最可怕的不是稳态大风，而是"逼近—过境—平息"的完整弧线

## 海上天气现象清单（设计候选池）

| 现象 | 与风的关系 | 视觉/听觉表现 | 玩法影响 |
|------|-----------|--------------|----------|
| **降水**（毛毛雨/阵雨/暴雨） | 弱相关 | 雨幕粒子、海面雨点涟漪、能见度下降、雨声 | 能见度↓ 导航变难 |
| **海雾**（平流雾） | **负相关**（小风才有雾） | 能见度骤降到几十米、世界灰白、声音发闷 | 最强导航威胁，"幽灵海"氛围 |
| **雷暴/飑线** | 阵风锋：风速突变 | 闪电照亮云层、雷声延迟到达、乌云墙逼近 | 突发大风，措手不及 |
| **阵风**（squall gust） | 短时波动 | 浪面出现黑色风痕带（cat's paws）快速移动 | 船体瞬时倾斜 |
| **浪涌**（远处风暴的余波） | 可脱节 | 风停了但大涌还在（长周期涌浪先到） | "风暴将至"的预警 |
| **昼夜** | 无关但调制一切 | 日出日落、夜晚风暴的恐怖感 | 氛围倍增器 |

愿景文档点名的标志性画面"暴雨中能见度骤降"目前完全不存在。

## 核心设计：三轴 + 天气锋面过境模型

### 轴的定义（全部连续量 0..1，不再只有离散档位）

| 轴 | 含义 | 驱动什么 |
|----|------|---------|
| `wind` | 背景风力 | 海况档位混合（现有）、云量、天空、音效 |
| `precip` | 降水强度 | 雨幕粒子密度、海面涟漪、能见度、雨声 |
| `fog` | 海雾浓度 | 能见度（与降水共用但独立）、声音闷化 |

另有一个**瞬态通道** `gust`：叠加在 wind 上的短时尖峰（飑线/阵风），衰减时间几十秒。

### 天气事件 = 轴的编舞

天气不再"随机跳档"，而是以**事件**为单位生成，每个事件是一段轴参数的剧本：

| 事件 | 时长 | 剧本 |
|------|------|------|
| 晴好期 | 3~8 min | wind 低位波动，precip=0，fog=0 |
| 锋面降雨 | 2~5 min | 云层先增厚 → precip 缓升 → wind 随锋面升 1~2 级 → 雨过天晴 |
| 雷暴飑线 | 3~6 min | 远处闪电+雷声渐近 → 阵风锋 gust 尖峰（wind 瞬间 +2~3 级）→ 暴雨 → 快速过境 |
| 海雾 | 2~6 min | 只在 wind 低位时触发：fog 缓升，能见度 3km→100m；风起则雾散 |
| 涌浪预警 | 1~3 min | 长周期涌浪到达（浪高+周期改变但风不变）→ 预示后续风暴事件 |

事件之间由马尔可夫链连接，但转移概率与当前轴状态耦合（例如：大风中不触发海雾；连续两个雷暴的概率低）。

### 能见度作为一等公民

`visibility = f(fog, precip, 昼夜)` 输出给：渲染雾参数、HUD  nautical 提示（"能见度 500m"）、未来的航行危险系统。

## 各系统的接入点

| 子系统 | 输入 | 实现 |
|--------|------|------|
| 海面（WaveProvider） | wind（+gust） | 现有档位混合改为连续风级→波参数插值（蒲福表连续化） |
| 天空（sky.gdshader） | wind, precip, 事件阶段 | 云量/云底高/云色；雷暴时云底压暗 |
| 雨幕 | precip | GPUParticles 雨幕 + 海面涟漪 shader 项（小尺度高频法线扰动） |
| 闪电 | 雷暴事件 | 随机方向闪光：天空瞬时增亮 + 平行光脉冲；雷声延迟 = 距离感 |
| 海雾 | fog | 距离雾密度（现有插值通道）+ 天空灰白化 |
| 音效 | wind, precip, 雷暴事件 | 风声分级、雨声、雷声延迟 |
| 水下 | precip, wind | 暴雨时水下浑浊度上升、水面白噪声化 |

## 蒲福风级连续化（海面参数表）

取代离散三档，wind 轴按蒲福表连续插值波参数（关键行）：

| 风级 | 风速 kn | 有效浪高 m | 海面观感 |
|------|---------|-----------|---------|
| 2 | 4-6 | 0.2 | 涟漪，无白沫 |
| 4 | 11-16 | 1.0 | 小浪，偶发白沫 |
| 5 | 17-21 | 2.0 | 中浪，白沫常见 |
| 7 | 28-33 | 4.0 | 大浪，白沫成带 |
| 9 | 41-47 | 7.0 | 狂浪，飞沫开始 |
| 11 | 56-63 | 11.0+ | 非凡巨浪（慎入） |

实现：把现有 `SEA_STATES` 三档改为 6 档插值表，`WaveProvider` 按连续 wind 值在相邻档间插值（现有混合机制可直接复用）。

## 开放问题（已拍板 2026-10-07）

1. **风级上限**：✅ 做 9 级以上非凡巨浪（需在浮力/穿浪上加强保护）
2. **天气杀伤性**：✅ 影响航行机制——强风产生风压差让船漂移/难控，海雾暴雨的能见度是真实导航威胁
3. **雷暴频率**：✅ 罕见惊喜（期望间隔 20~40 分钟，有过境冷却）
4. **昼夜循环**：✅ 做——单独阶段 W6，天空控制权与天气系统合并设计（昼夜调制太阳高度角，天气轴调制云/雨/雾）
