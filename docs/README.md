# 项目文档与进度管理

本文件夹用于管理 **ocean（大海模拟器）** 项目的开发进度与设计文档。

## 目录结构

```
docs/
├── README.md                        ← 本文件（索引与维护约定）
├── PROGRESS.md                      ← 开发进度总览：里程碑、当前状态、下一步
└── design/                          ← 设计文档
    ├── 01-game-vision.md            ← 游戏愿景与核心体验目标
    ├── 02-technical-direction.md    ← 技术选型分析（海面/天气/天空/物理）
    └── 03-prototype-architecture.md ← 原型架构说明与调参指南
```

## 维护约定

1. **每完成一个可玩的里程碑**，更新 `PROGRESS.md`：勾选完成项、记录验证数据、更新"下一步"。
2. **每做一个重要技术/设计决策**（选型、取舍、否决方案），记录到对应 design 文档的"决策记录"小节，写明理由，避免日后反复纠结同一个问题。
3. **架构发生变化时**（新增模块、改动核心接口），同步更新 `design/03-prototype-architecture.md`（或新文档），保证文档即现状。
4. 文档全部使用中文，文件名用英文小写 + 数字前缀排序。
